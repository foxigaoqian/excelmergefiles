Merge Excel Files Online

Combine multiple XLSX, XLS, or CSV files without sending spreadsheet contents to an application processing server. Choose Append Rows to combine similar tables into one worksheet, or Keep Sheets to place source worksheets in one output workbook.

How to merge Excel files

  1. Select two or more supported files.
  2. Choose Append Rows or Keep Sheets.
  3. Arrange files in the required processing order.
  4. Configure source columns and identical-row removal.
  5. Merge, download, and verify the output in Excel.

Append Rows or Keep Sheets?

Append Rows works best when files use similar headers and should become one table. Keep Sheets is better when each workbook or worksheet should remain separate.

Common use cases

Typical uses include monthly sales reports, expense exports, inventory lists, survey responses, CRM exports, and recurring CSV downloads.

Example

If January.xlsx and February.xlsx both contain Date, Order ID, and Revenue columns, Append Rows creates one worksheet containing both months. Keep Sheets creates separate January and February tabs.

What may not be preserved

Charts, macros, external connections, advanced styling, workbook settings, and unsupported formulas may change or be removed. Keep the original files and verify the result before important use.

Troubleshooting

Columns do not line up

Make header names consistent before merging. Different names are treated as separate output columns.

Dates look different

Excel serial dates, text dates, and regional formats may be interpreted differently. Review all date columns after download.

The browser becomes slow

Large workbooks consume browser memory. Process fewer or smaller files at a time.

Frequently asked questions

Can I combine XLS and XLSX files?

Yes, within the features supported by the browser spreadsheet library.

Can duplicate rows be removed?

The tool can remove rows that are completely identical across all output columns. It does not deduplicate by one selected key.

Are files uploaded?

Spreadsheet contents are processed in the browser tab. Hosting and static asset providers may receive ordinary web request data, but the selected file contents are not sent to an application processing server.
