Privacy Policy

Last updated July 18, 2026.

Local spreadsheet processing

The spreadsheet tools are designed to read and generate files inside the active browser tab. The application does not intentionally send spreadsheet file contents to an application processing server.

Hosting and network requests

Hosting, CDN, security, DNS, font, and web-resource providers may process standard request information such as IP address, browser type, requested page, time, referrer, and error logs.

Generated downloads

Generated files are downloaded through the browser. The current interface does not create a cloud file account or a personal workbook history.

Sensitive files

Confirm your organization’s policies before processing confidential or regulated information. Keep secure backups and do not send private workbooks when reporting a technical issue.

See the contact page for technical or privacy questions.
